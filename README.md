# Abhik Chakraborty – Portfolio

3D animated portfolio built with three.js, GSAP ScrollTrigger and Lenis. Single-file site: open `index.html` or deploy to Vercel / GitHub Pages.

## Credits
- 3D model: "Damaged Helmet" by theblueturtle_, licensed CC BY 4.0
- Smooth scroll: Lenis, animation: GSAP, 3D: three.js

`assets/DamagedHelmet.glb` is the original model file (already embedded inside index.html, kept here for reference).
